# 002. 教科書與學術期刊管道與實體路徑分離

- **狀態**：Accepted
- **日期**：2026-09-23
- **決定者**：Antigravity Agent, User

## 背景與問題陳述 (Context)
大學教科書與學術期刊論文具有截然不同的版面幾何結構。教科書重視章節拆分、學習目標與章末總結；期刊論文則強調雙欄排版、IMRAD 架構與作者資訊。若混雜於同一套解析管線，會引發大量規則衝突與例外處理。

## 決策內容 (Decision)
1. 實體劃分路徑，採取「路徑即路由」模式。
2. 拆分為獨立的 `TextbookPipeline` 與 `LiteraturePipeline`，各自主管領域排版解析。
3. 共享底層 PDF/EPUB 影像與文字萃取、表格解析與數學符號轉換器。

## 後果與影響 (Consequences)
- **正面影響**：大幅簡化各管線邏輯，期刊與書籍之特定需求（如雙欄切分 vs 章節切分）互不干擾。
- **負面影響**：維護兩套 Pipeline 的生命週期協調。
