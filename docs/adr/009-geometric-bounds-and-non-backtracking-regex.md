# ADR-009：版面元件解析之嚴格幾何邊界收斂與線性時間跨頁流向縫合

- **狀態**：Accepted
- **日期**：2026-10-23
- **Agent**：`antigravity`
- **任務**：`TASK-039`, `TASK-040`

## 1. 背景與問題

在對數百頁的大型數位教科書（如 Cengage、Pearson、Wiley 出版社）進行無人值守全量批次轉換時，系統遇到了以下穩定性與語義完整性瓶頸：
1. **災難性正則回溯 (Catastrophic Regex Backtracking)**：在跨頁段落流向縫合 (`stitch_cross_page_continuity`) 中，處理包含密集條目與無標點符號的頁面（如 Glossary 附錄）時，因巢狀貪婪正則量詞引發回溯爆炸，進程卡死超過 8 小時。
2. **語義元件幾何越界誤吞本文**：
   - 章末解析器 (`EndOfChapterParser`) 依賴不分大小寫的字串匹配，將內文中的普通小寫單字（`summary`, `references.`）判定為章末結構，導致後續正文被整頁截斷並洩漏 Cengage WCN 頁尾版權聲明。
   - 邊欄解析器 (`MarginParser`) 缺乏右邊界寬度幾何硬約束，將靠左對齊但寬達 386 pt 的主文大標題與段落當作邊欄術語吞噬。
3. **程式語言關鍵字碰撞**：單詞 `class` 在非程式碼類書籍（如心理學之 `social class worldview`）被貪婪標記為 Python 代碼塊。

## 2. 評估過的方案

| 方案 | 優點 | 缺點 |
|---|---|---|
| A. 仰賴後續 AI 模型（Ollama Healer）修復 | 無需大幅重構確定性規則 | 處理時間極長，耗費大量 GPU 資源，且對長文本截斷無能為力 |
| B. 降低章節字數門檻並放寬驗證容忍度 | 減少報錯中斷 | 犧牲轉換產物質量，殘留大量雜訊與缺漏，無法滿足專業出版標準 |
| C. (Selected) **雙軌幾何邊界硬約束 ＋ 線性時間無回溯正則規格** | 1. 正則全面線性化，插播內容施加行數上限，杜絕指數級回溯<br>2. 版面元件抽取強制綁定字級、粗體、寬度與水平邊界硬約束<br>3. 語義代碼區塊嚴格檢查語法簽名與非空行數計數 | 需要全面校驗各解析模組的幾何與樣式參數 |

## 3. 決策與理由

採納 **方案 C**：
1. **正則表達式線性時間保證**：
   - 跨頁連續性縫合重構為非巢狀單行比對，並限制插播行數 `{1, 20}`，將回溯複雜度嚴格限制在線性時間 $O(n)$ 內。
2. **版面元件之幾何硬約束**：
   - `EndOfChapterParser` 強制標題不可為全小寫，且必須符合標題字級（`size >= 12` 或 `is_bold` 或 `isupper()`），水平線上左側不可有其他文字。
   - `MarginParser` 引入右邊界與最大寬度限制（`width <= 200 pt` 且 `x1 <= margin_bound + 40`），並依據書籍設定守衛執行。
3. **語法簽名精確識別**：
   - 程式碼關鍵字採用具備語法特徵之模式（如 `\bclass\s+[A-Za-z_]\w*\s*(?:\([^)]*\))?\s*:`），並要求有效程式碼塊具備 `>= 2` 行非空內容。
4. **輸出全域安全清洗保險**：
   - 在 `digital_pdf.py` 輸出 Markdown 前，配置全域保險清洗正則，杜絕出版商 WCN 宣告遺漏。

## 4. 影響與代價

- **正面影響**：
  - 4 本大型教科書共 97 個章節在全量重跑中達成 **100% 直通通過 (`ALL_PASSED`)**。
  - 長附錄與名詞解釋處理時間由無窮回溯降至 **0.19 秒**。
  - 正文標題與段落完整性達到出版級水準，無內文被邊欄誤吞。
- **代價與維護**：
  - 各模組需要保持對 Profile 幾何參數的高度同步與校驗。
