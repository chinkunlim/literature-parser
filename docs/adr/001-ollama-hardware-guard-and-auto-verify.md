# 001. 本地 Ollama 離線硬體防護與自我修復管線

- **狀態**：Accepted
- **日期**：2026-09-23
- **決定者**：Antigravity Agent, User

## 背景與問題陳述 (Context)
在書籍與文獻轉檔過程中，過往若本地 Ollama 服務離線或硬體資源不足（例如電池低電量、RAM 不足），若強制啟動大模型修復容易導致系統卡死或假修復。

## 決策內容 (Decision)
1. 建立硬體防線（Hardware Guard），在呼叫模型前強制檢查可用 RAM（≥ 2.0GB/4.0GB）、磁碟空間（≥ 10GB）與供電狀態。
2. 本地 Ollama 僅綁定 `http://127.0.0.1:11434`，離線時自動優雅降級為規則修復或人工複審隔離。
3. 輸出異常時以單元化 Recipe 機制（Fix Playbook）進行自我修復。

## 後果與影響 (Consequences)
- **正面影響**：極致穩定，避免密集運算造成系統卡死，並確保資料 100% 留存於本地。
- **負面影響**：硬體受限時部分複雜語意修復功能會降級為隔離待覆核。
